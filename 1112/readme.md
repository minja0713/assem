# MASM 32-bit Assembly

## 5개의 정수 입력 및 합계와 평균 계산

### Description
MASM 32비트 어셈블리어를 사용하여 정수 5개를 입력받고 합계와 평균을 계산하는 프로그램입니다.

### Features
- 입력받은 정수 5개 저장
- 입력한 정수의 합계 계산
- 입력한 정수의 평균 계산
- 합계와 평균 출력

### Execution Result

```text
Enter 5 integers: 10 20 30 40 50

Sum = 150
Average = 30
```

### Language
- MASM (32-bit Assembly)
